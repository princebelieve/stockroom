STOCKROOM BUSINESS

Devices tested in real business use

Stockroom has been used for real transactions with receipt printing, A4 printing and barcode scanning. The product owner confirmed these models.

FeaturesWorkspacesDevicesGet startedDownloadsSupport

Receipt printer: DKT-M81

XPrinter DKT-M81, used successfully with Stockroom in real transactions. Owner-supplied printing-speed specification: 230 mm/s. Configure the receipt printer and paper size in Printers & devices.

A4 printer: HP LaserJet P1102

Used successfully with Stockroom for document printing. The owner identified its toner as HP 85A / CE285A. Install the appropriate printer driver and select the printer in the app’s device settings.

2D barcode scanner: model 8120

Used successfully with Stockroom. Configure scanner input and its terminator on each checkout, then test a known product barcode. The connection type was not supplied with this model report.

Windows, Android and PWA

Use a Windows checkout, Android app or browser/PWA. On iPhone and iPad, install the PWA through Safari’s Add to Home Screen. Available printing and device connections depend on platform and setup.

Printer routing

Configure receipt and preparation printer actions for the device. The app retains preparation print jobs for retry when printing needs attention. Test your own driver, paper width and kitchen/bar routing before trading.

Scales and other devices

Weighed-goods setup supports keyboard-output readings and configured EAN-13 weight labels. No weighing-scale model has been physically tested for this installation. Devices that require a proprietary protocol need a compatible connection; included manufacturer software can provide drivers but does not establish every app integration.
